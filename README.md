# 🚀 EduTrackPro

EduTrackPro is a smart coaching management system built using Flask and SQLite.

## 📌 Features
- Add student details
- Store data in database
- View all students in table format
- Automatic alert system:
  - Low Attendance (<75%)
  - Fees Pending
- Real-time status display

## 🛠️ Tech Stack
- Python (Flask)
- HTML, CSS
- SQLite Database

## 🎯 Project Purpose
This project helps coaching institutes manage student data efficiently and automatically detect important issues like low attendance and pending fees.
